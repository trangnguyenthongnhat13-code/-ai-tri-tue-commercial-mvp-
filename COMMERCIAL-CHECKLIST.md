# Commercial checklist sau MVP

MVP này đủ để Trang dùng như người dùng đầu tiên và tạo case study thật. Trước khi bán đại trà, cần khóa thêm:

- Đăng nhập/tài khoản khách hàng
- Subscription + thanh toán
- Quota audio / ảnh / video / nghiên cứu
- Dashboard hiển thị quota còn lại
- Lưu trữ cloud cho output
- Theo dõi chi phí API theo user/job
- Hàng đợi render video
- Chính sách dữ liệu & điều khoản sử dụng
- Backup/retry khi API lỗi
- Admin dashboard
- Domain thương hiệu riêng
